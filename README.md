# Movie Theater Box Office & Concession Analysis

## Project Overview
This project analyzes movie theater sales data to understand ticket bookings, movie performance, showtime trends, screen formats, and concession sales.

The analysis helps identify useful business insights that can support better decision-making in cinema operations.

## Analysis Performed

The project covers the following areas:

1. Loading and inspecting the dataset.
2. Checking missing values and duplicate records.
3. Cleaning and preparing the data.
4. Analyzing movie genres.
5. Identifying the top 10 movies.
6. Analyzing showtime performance.
7. Comparing weekday and weekend sales.
8. Analyzing screen formats.
9. Studying large group bookings.
10. Analyzing ticket and concession sales.
11. Generating cleaned and summarized output files.

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Open the project folder in VS Code and execute:

```bash
python src/Movie_theatre_analysis.py
```

## Output

The analysis results are saved as CSV files in the `Output` folder.

These files contain cleaned data and summarized information from the analysis.

## Conclusion

This project provides an understanding of movie theater sales and customer booking patterns using Python, Pandas, and NumPy. The results can help cinema management understand business performance and make better operational decisions.
